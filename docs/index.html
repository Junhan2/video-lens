video-lens

영상을 눈대중으로 보지 않고 잽니다. 모든 처리는 내 Mac 안에서.

Claude는 영상을 직접 보지 못합니다. video-lens는 영상을 프레임 단위로 재서 숫자와 글로 먼저 건네고, 확인이 필요한 장면만 이미지로 보여 줍니다.

60fps에서 300ms 애니메이션은 18프레임. 초당 2장만 보면 0~1장에 담깁니다.

하는 일

UI 모션을 CSS로

애니메이션의 시작, 길이, easing(cubic-bezier), 요소 사이 지연을 프레임 단위로 재서 CSS로 내줍니다.

강의·데모를 시각별로

장면 전환, 슬라이드 글자(한국어 포함), 음성 받아쓰기, 소리와 화면의 어긋남을 시각과 함께 정리합니다.

업로드 없음

ffmpeg, OpenCV, macOS Vision, 기기 안 음성 인식, whisper.cpp만 씁니다. 영상과 음성이 밖으로 나가지 않습니다.

/watch (claude-video 0.1.3)video-lens
보는 프레임초당 최대 2장, 최대 100장모든 프레임
시각 정밀도초 단위프레임 단위(60fps면 ±16.7ms)
300ms 애니메이션0~1장에 담김길이, easing, CSS 값까지 측정
음성영어 자막이 없으면 오디오를 Groq/OpenAI로 업로드기기 안에서 받아쓰기(한국어 포함)
장면 전환·화면 글자없음컷 시각, 슬라이드별 글자

/watch는 대략적인 내용을 빨리 보는 데, video-lens는 "언제, 얼마 동안, 어떻게"를 재야 할 때 알맞습니다.

언제 강한가

  • 긴 영상: 10분 한국어 강의는 Opus 기준 비용 30%, 시간 74%가 줄었습니다.
  • 반복되는 모션: 캐러셀처럼 되풀이되는 전환을 한 번에 묶어 재서 비용이 절반 이하로 줄었습니다.
  • 한국어 강의·회의 녹화: 음성을 밖으로 보내지 않고 받아쓰고, 슬라이드 글자를 시각과 함께 뽑습니다.
  • 디자인 검수: "이 전환 400ms에 ease-out 맞아?"처럼 숫자로 답해야 하는 질문.

짧은 영상의 한 줄 요약처럼 가벼운 질문에는 필요 없습니다. 여러 요소가 겹쳐 움직이는 화면은 "왼쪽 목록만"처럼 볼 영역을 알려 주면 더 정확합니다.

설치

Claude Code에서:

/plugin marketplace add Junhan2/video-lens
/plugin install video-lens@video-lens

터미널에서:

brew install ffmpeg
pip3 install opencv-python numpy
xcode-select --install

macOS 전용이며 macOS 26(Apple Silicon)에서 시험했습니다. 기기 안 음성 인식은 macOS 26부터 됩니다. whisper.cpp 모델, Node 24와 Chrome, yt-dlp는 선택입니다. 자세한 내용은 README를 보세요.

설치한 뒤에는 평소처럼 말하면 됩니다. 이 화면녹화 애니메이션을 CSS로 분석해줘
